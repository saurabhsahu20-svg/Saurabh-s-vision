# VISION ONE — PDF Scanner (Android beta)
Scan Smart. Save Simple.

Android 8+ CameraX PDF scanner; capture document photos, batch pages, clean question paper images, reorder/rotate/convert pages to A4 PDFs, local PDF library, preview, share, print, import photos, OCR Hindi and English, merge/split/compress generated PDFs.

## Build
GitHub Actions -> VISION ONE APK Build -> workflow run -> Artifacts -> VISION-ONE-Android-APK. Android SDK/Gradle needed to build locally.

**Beta warning:** Compiled source is not equivalent to a production certification or complete implementation of every advanced requirement (true quadrilateral edge detection, perspective correction, fully automatic document triggering, guaranteed searchable PDF overlay). Do not claim these features as validated.
